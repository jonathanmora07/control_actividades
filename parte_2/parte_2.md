git status
git add README.md
git commit -m "Actualiza documentación"
git push
Explica qué ocurre en cada instrucción.

el git status sera oara ver el estado de los archivos locales 
el git add es para perparar dichos archivos 
el git commit es para tener todos los cambios listos y echos 
git commit es la actualizacion de comandos 
y el git push es comando para subirlos
